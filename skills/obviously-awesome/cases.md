<a id="obviously-awesome---case-studies"></a>
# Obviously Awesome——案例研究

<a id="successful-repositionings"></a>
## 成功的重新定位

<a id="janna-systems--crm-for-investment-banks-big-fish-small-pond"></a>
### Janna Systems → 投资银行的 CRM：小池塘里的大鱼

以“所有人的 CRM”定位时表现不佳。公司认识到，广义 CRM 品类已有明确领导者，于是缩小定位：“投资银行的 CRM”。结果：收入在 18 个月内从 200 万美元增至 7,000 万美元，随后被 Siebel 以 17 亿美元收购。

**启示：** 进入细分市场，往往胜过与品类领导者正面竞争。

<a id="eloqua--marketing-automation-create-new-game"></a>
### Eloqua → “营销自动化”：开创新游戏

最初定位为“需求生成自动化”。Mark Organ 的团队创造了“营销自动化”这一名称，以便更清楚地区别于邮件自动化工具。结果：收入从 2006 年的 1,200 万美元增至 2012 年 IPO 时的 9,600 万美元，随后被 Oracle 以 8.7 亿美元收购。

**Mark Organ 谈品类创造：** “最成功的品类创造，并非来自公司高管在外出研讨会上想出一个缩写词，而是来自对一小群客户的深入理解。这些客户往往是**‘怪人’，他们的态度与行为非常极端**，由技术与社会的巨大转变塑造。当且仅当这些异乎寻常的态度和行为成为主流时，品类才会浮现。品类创造是一项艰难、缓慢的工作，但成功后的回报巨大。”

<a id="wave--free-invoicing-for-solo-small-business"></a>
### Wave → 面向个体小企业的免费开票工具

发现小企业客户中有一小群人特别喜欢简单的开票功能。公司围绕他们构建定位，忽略其余人群，取得显著增长。

**启示：** 最匹配的客户会揭示正确定位。

<a id="arm--hammer--deodorizercleaner"></a>
### Arm & Hammer → 除臭剂／清洁剂

原本作为烘焙原料销售，销售额为 1,600 万美元。重新定位为除臭剂／清洁剂后，到 1987 年销售额增至 3.18 亿美元。物理产品相同，只是摆脱了旧定位包袱。

**启示：** 同一个产品，在不同定位下可能产生截然不同的商业结果。

<a id="wattpad--storytelling-platform-with-tv-adaptation"></a>
### Wattpad → 可改编为电视节目的故事平台

Wattpad 于 2006 年起步，帮助作者在网上创作故事。随着 Apple App Store 在 2009 年推出以及移动阅读增长，平台围绕读者与作者社区重新定位。后来进一步利用受众优势：2014 年，Wattpad 与电视制作人合作推出“Wattpad Presents”，将热门 Wattpad 故事改编成电视剧。重新定位让公司证明了一种新商业模式——为电视提供故事 IP；这一模式在最初的“写作平台”框架下难以实现。

**启示：** 跟踪受众实际使用产品的方式，可以发现有助于打开新商业模式的定位变化。

<a id="redgate--database-devops-trend-layer"></a>
### Redgate → 数据库 DevOps：趋势叠加

这家数据库工具公司将“DevOps”趋势叠加到定位上，形成“数据库 DevOps”。结果：主动上门的潜在客户增加 100%。

**启示：** 当趋势确实与产品优势、客户情境相交时，叠加趋势可以放大定位效果。

<a id="failure-examples"></a>
## 失败案例

<a id="bic-for-her-style-3-failure"></a>
### Bic for Her：第三种方式的失败

试图创造“女性专用笔”这一新品类。笔就是笔，客户对此嘲笑，产品线最终被撤下。

**启示：** 能给新品类起名字，不代表它就是真正的品类。

<a id="sharing-economy-for-pets--uber-for-cats-trend-layer-failure"></a>
### “宠物共享经济”／“猫咪版 Uber”：趋势叠加失败

试图把“共享经济”趋势叠加到一个实际上没有共享经济机制的产品上。客户无法理解这个类比，最终失败。

**启示：** 只有趋势与产品实际情况真正相交，趋势叠加才有效。

<a id="long-island-iced-tea--long-blockchain-trend-layer-failure"></a>
### Long Island Iced Tea → Long Blockchain：趋势叠加失败

这家饮料公司在 2017 年为追随加密货币趋势而更名，最终被纳斯达克摘牌。

**启示：** 缺乏产品与战略实质、只为追随趋势更名，会向市场传递绝望的信号。

<a id="cool-purple-lights-cio-story-customer-attitude-shift"></a>
### “炫酷紫色灯光”的 CIO 故事：客户态度变化

April 的轶事：21 世纪初的一段时期，IT 厂商会在服务器上装炫酷的紫色 LED，因为 CIO 喜欢机房里的这种效果。几年后 CIO 已不再在意，因为云计算正在改变 IT 关注重点。围绕硬件外观定位的厂商，背上了不再有效的旧包袱。

**启示：** 客户态度会变化，因此需要定期检查定位。

<a id="counter-example-big-fish--small-pond-done-right-coke-for-dogs"></a>
## 对照案例：正确运用“小池塘里的大鱼”——“狗狗可乐”

Dunford 的假设案例：把可乐重新定位到宠物零食细分市场（“骨头味”）。竞争对手、价值和品类不同——产品相同。

**要点：** 有时确实存在细分市场，你只需要创造性地寻找。产品很像可乐，棕色、有气泡，但又能做到普通可乐做不到的事：有骨头味，而狗非常、非常想要这种味道。

这就是“小池塘里的大鱼”的概念模型：不改变产品，改变细分市场和定位。

## 客户销售叙事案例

<a id="aprils-database-product-step-through-example"></a>
### April 的数据库产品：逐步演示

**背景：** 数据库产品以“其他数据库”为竞争参照。销售周期长，潜在客户将其与 Oracle 等领导者比较。

**客户访谈发现：**
- 最匹配的客户实际上是在她的产品与 BI 工具／数据仓库之间选择。
- 品类错了，竞争战场就错了。

**重新定位：**
- 第四步，替代方案：BI 工具、数据仓库。
- 第五步，属性：实时分析、数据库模式的灵活性、集成深度。
- 第八步，参照框架：重新定位为具备分析能力的数据仓库。
- 结果：销售周期缩短，潜在客户更快理解产品。

**启示：** 客户拿你与谁比较，决定你能否胜出。

<a id="appointment-scheduling-software"></a>
### 预约排期软件

- 初次细分：“网点很多的公司”——太模糊。
- 改进细分：“金融服务和报税服务”——具备行为特征。
- 细分变得具体后，整个定位便清晰了。
