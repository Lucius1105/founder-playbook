## 完整实例：SaaS 项目管理工具

```text
=== 品牌故事脚本 ===

公司／产品：TaskFlow（项目管理 SaaS）

1. 角色
   愿望：项目按时完成，不再混乱。
   生存类别：节省时间 + 获得地位。

2. 问题
   反派：组织混乱、沟通分散。
   外在：“项目延期、预算超支。”
   内在：“我觉得正在失去控制，而且很丢脸。”
   理念：“团队不该为了保持协调，就必须这么辛苦。”

3. 向导
   共情：“我们管理过复杂项目，知道在邮件、Slack 和表格之间追问进度有多烦。”
   权威：“超过 5,000 个团队信任我们，包括［标志］［标志］［标志］。”

4. 计划
   第一步：连接你的工具，两分钟设置完成。
   第二步：一个视图看清全局，由我们自动整理。
   第三步：按时交付，并因此赢得好评。

   计划名称：“清晰系统”。

   承诺计划：
   - 免费试用 14 天，无需信用卡。
   - 随时一键取消。
   - 数据始终可以导出。

5. 行动号召
   直接型：“开始免费试用”。
   过渡型：“下载《项目挽救检查表》，免费 PDF”。

6. 失败
   - 项目持续延期，利益相关者失去信心。
   - 团队因不断救火而倦怠。
   - 你成为所有人责怪的瓶颈。

7. 成功
   - 项目按时上线，利益相关者看得到。
   - 团队把时间用于建设，而非汇报状态。
   - 你被视为让混乱恢复秩序的领导者。

8. 转变
   从：不堪重负、不断追问进度的项目经理。
   到：能稳定交付的自信领导者。
```

## 一句话介绍工作表

**公式：**［问题］+［解决方案］+［结果］。

```text
问题：用一句话点出痛苦。
_________________________________________________

解决方案：用一句话说明提供什么。
_________________________________________________

结果：用一句话描绘成功。
_________________________________________________

合并后的一句话介绍：
_________________________________________________
_________________________________________________
_________________________________________________
```

### 完整示例

**理财顾问：**
“多数人对退休感到焦虑，因为规划太复杂。我们用一次会面，为你制定简单、个性化的计划。我们的客户能够自信退休，不再困惑。”

**网站设计机构：**
“小企业每天都因网站让访客困惑而失去客户。我们使用经过验证的信息表达框架重做网站。我们的客户在 30 天内就能看到更多销售线索。”

**净菜餐包服务：**
“忙碌的父母因给孩子吃加工食品而内疚。我们配送预先分装的健康餐食，烹饪只需 15 分钟。全家可以轻松坐下来，好好吃一顿饭。”

**网络安全公司：**
“多数企业直到为时已晚，才意识到自己有安全漏洞。我们全天候监控系统，在威胁袭来前将其阻止。客户知道数据安全，就能安心入睡。”

## 自动邮件序列模板

### 培育序列（下载引流资料之后）

**邮件一：交付与欢迎**，立即发送。
```text
主题：你的［引流资料名称］在这里
正文：
- 交付资料，附下载链接。
- 一句共情：“我们知道［问题］让人沮丧。”
- 一句向导定位：“我们已帮助［X］人解决这个问题。”
- 温暖落款。
- 不推销。
```

**邮件二：价值**，第三天发送。
```text
主题：［一条与其问题相关的技巧］
正文：
- 提供真正有用的技巧或洞见。
- 关联对方下载资料想解决的问题。
- 保持简短，150—250 词。
- 不推销。
```

**邮件三：故事**，第五天发送。
```text
主题：［客户姓名］如何从［问题］走向［成功］
正文：
- 把转变型证言讲成故事。
- 之前：他们在什么问题上挣扎。
- 转折：如何找到你。
- 之后：现在生活是什么样。
- 自然传达定位，不强推销售。
```

**邮件四：价值**，第八天发送。
```text
主题：［另一条有用的洞见］
正文：
- 再提供一个技巧、资源或视角。
- 建立信任并展示专业能力。
- 不推销。
```

**邮件五：销售**，第十一天发送。
```text
主题：准备好［实现理想结果］了吗？
正文：
- 简短重述问题与利害。
- 提出解决方案和清晰行动号召。
- 包含三步流程计划。
- 添加承诺计划元素，如保证、无风险。
- 放直接行动按钮。
```

**邮件六：价值**，第十五天发送。
```text
主题：［再提供一个洞见，维持关系热度］
正文：
- 提供价值。
- 与尚未准备购买者保持关系。
- 适当时轻轻提及所提供的产品或服务。
```

## 转变型证言收集模板

发给满意的客户：

```text
主题：能帮个小忙吗？你的故事可能帮到有相似处境的人。

你好，［姓名］：

我们很想分享你的经历。方便回答这四个问题吗？
大约需要五分钟。

1. 找到我们之前，你在应对什么问题？

2. 尝试解决它时，那种挫败是什么感受？

3. 与我们合作有什么不同？

4. 现在你的生活或生意是什么样？

想写多少都可以。让故事真实的是你的话，而不是我们的话。

谢谢！
［你的姓名］
```

**如何整理回答：**

```text
“［第一题答案：问题］。［第二题答案：感受］。
后来我找到［品牌］。［第三题答案：不同之处］。
如今［第四题答案：转变］。”

——［客户姓名］，［职衔／公司］
```

## 引流资料标题公式

选择一种形式，再填空：

```text
“让［受众］遭受［坏结果］的［数字］个错误”
例：“让屋主在装修上多花数千美元的五个错误”

“［受众］实现［理想结果］的指南”
例：“新任经理自信带队指南”

“如何不受［痛点］困扰，也能［实现理想结果］”
例：“如何增加收入，又不让团队累垮”

“在［时间范围］内实现［理想结果］的［数字］个步骤”
例：“每天 15 分钟，三步让家更整洁”

“［理想结果］检查表”
例：“网站上线准备检查表”

“你正在犯这［数字］个［问题］错误吗？”
例：“你正在犯这七个招聘错误吗？”
```

## 快速诊断：你的表达有效吗？

逐项打 1—5 分：1 表示缺失，5 表示极其清楚。

```text
[ ] 网站第一行就说明客户愿望                              ___/5
[ ] 明确点出反派或问题                                    ___/5
[ ] 回应内在感受，而非只有外在问题                        ___/5
[ ] 品牌定位为兼具共情与权威的向导，而非英雄              ___/5
[ ] 有清晰计划，如三步计划                                ___/5
[ ] 直接行动号召明显可见，并重复出现                      ___/5
[ ] 利害清楚，说明不行动会怎样                            ___/5
[ ] 成功图景具体，不是模糊的“改善”                        ___/5
[ ] 暗含身份转变，即从何种状态走向何种状态                ___/5
[ ] 初次访客五秒内就能解释你做什么                        ___/5

总分：___/50

40 分以上：表达有力，优化细节。
25—39 分：已有核心结构，但缺口正在损害转化。
低于 25 分：需要大幅重写，从 BrandScript 开始。
```
