# 100m-leads — 案例与路线图

<a id="a-decade-in-a-page"></a>
## 用一页概括十年经验

Hormozi 对整套框架的浓缩总结：

1. **线索与有互动的线索**——你需要的是表现出兴趣的人，而非单纯的名单数量。
2. **引流品**——用免费价值，把普通线索转化为有互动的线索。
3. **核心四渠道**——让人知道你，只有4种基本方式：
   - 熟人触达：问对方是否认识有需要的人。
   - 发布内容：吸引、留住、回报。
   - 陌生开发：名单＋个性化＋快速提供大量价值＋足够数量。
   - 付费广告：定向＋点名目标人群＋行动号召。
4. **更多、更好、更新**——先增加数量，再提高质量，最后尝试新方法。
5. **获客伙伴**——客户转介绍、员工、代理机构、联盟伙伴。
6. **100法则／达成目标再收工**——先设每日最低量，再按结果安排工作。
7. **路线图**——从0到1亿美元以上的7个阶段。

**复利循环：**

```
有互动的线索 → 客户 → 收入 → 员工 →
更多线索 → 更多客户 → 更多收入 → 循环
```

<a id="the-0-to-100m-roadmap-7-levels"></a>
## 从0到1亿美元的路线图（7个阶段）

这是分阶段推进的模型。具体收入门槛取决于行业利润率；更值得长期参考的是阶段结构。

| 阶段 | 描述 | 主要行动 |
|-------|-------------|----------------|
| **1** | 朋友知道你在做什么 | 熟人触达 |
| **2** | 一种方法能持续带来线索 | 把个人产能用足，做内容或陌生开发 |
| **3** | 员工帮你做推广 | 招人接手你已经做过的工作 |
| **4** | 产品好到能带来约25%以上的转介绍 | 聚焦产品，加倍投入转介绍 |
| **5** | 多种方法、多个平台 | 扩充团队，增加平台 |
| **6** | 管理者无需你介入也能运营部门 | 招聘有实战经验的负责人 |
| **7** | 超过1亿美元的业务机器全面运转 | 核心四渠道及所有获客伙伴同时发挥作用 |

**时间：** 即使知道每一步该怎么做，也需要5—10年。大多数企业会在某两个阶段之间停留多年。

<a id="the-many-sided-die-mindset"></a>
## 多面骰子（心态）

每个人都有一颗面数未知的骰子。一面是绿色，代表成功，其余是红色。

**规则：**

- 你看不到骰子有多少面。
- 掷到绿色：一个红面变成绿面，然后继续掷。
- 掷到红色：什么也不发生，然后继续掷。
- 停止掷骰子，就输了。

**启示：**

- 掷的次数越多，绿色越多。
- 只要掷得足够多，每颗骰子都会迎来连续出绿的阶段。
- 只要不放弃，就不会输。

**应用于推广：** 不尝试就不知道有没有效果。开始时会掷到红色，继续掷。尝试越多，事情越容易。

> 译注：以上保留原文的激励性比喻，不表示现实商业投入必然成功。

<a id="case-pattern-the-channel-spread-trap"></a>
## 案例模式：渠道铺得太散

一位创始人读到核心四渠道后，决定四路并进：每天50封陌生邮件、每天发 LinkedIn 内容、每天投20美元 Meta 广告，同时请熟人介绍。

**六个月后：**

- 陌生邮件：回复率0.3%，没有成交。
- 内容：200名关注者，没有线索。
- 广告：花了3,600美元，获得2位客户。
- 熟人触达：聊了5次，获得1位客户。

**诊断：** 四个渠道都没有得到足够的数量和注意力。精力分散，意味着每个渠道都投入不足。

**修正：** 选一个，停掉其他渠道。根据现有资源，把注意力集中到最有可能奏效的渠道。掌握之后再加下一个。

这是 Hormozi 最常处理的模式，也解释了为什么核心规则是“掌握一个，再增加一个”。

<a id="case-pattern-the-volume-underestimate"></a>
## 案例模式：低估所需数量

一位创始人做了30天陌生邮件开发，共发600封，约到3次会谈，没有成交，于是认定“陌生开发不适合我的市场”。

**诊断：** 30天600封，平均每天20封。按常见的1%—3%回复率，只会得到6—18条回复，其中并非都符合客户条件。考虑正常销售周期，30天可能还不足以促成成交。

**修正：** 这就是100法则存在的原因。每天100次，坚持100天，共10,000次尝试，才足够判断渠道是否适合市场；600次不够。

多数“这个渠道没用”的结论，实际意味着“我没有用足够大的量、持续足够久”。

<a id="case-pattern-the-offer-lead-mismatch"></a>
## 案例模式：方案与线索不匹配

一位创始人通过付费广告每月获得500条线索，但转为付费客户的比例只有0.5%。

**表面的修正：** “我需要更多线索。”

**真正的诊断：** 如果这些线索符合客户条件，0.5%的转化率指向的是方案问题。向有问题的方案继续导流，只会浪费更多广告费。

**修正：** 暂停获客工作，用 `100m-offers` 修正方案，再恢复引流。

因此，Hormozi 系列的使用顺序是 `mom-test → 100m-offers → money-models → 100m-leads`。给不好的方案引流，就是在浪费钱。

<a id="case-pattern-the-referral-engine"></a>
## 案例模式：转介绍引擎

一位创始人有50位满意客户，却从不请求转介绍，两年合计只有约3次转介绍。

**采取的修正：**

1. 客户刚取得重要成果时立即请求转介绍，由具体事件触发，而非泛泛地问。
2. 双方都有奖励，例如双方各得一张礼品卡。
3. 提供一键分享工具。
4. 跟踪并报告转介绍来源。

**多家企业中观察到的模式：** 有意识地建立机制后，转介绍数量会显著增加。其原因是：客户愿意介绍，但开口有些别扭，而且缺少方便的方式。

可执行的启示：拥有满意客户的企业，如果没有主动设计机制，往往会错失转介绍机会。明确的计划能把这些机会接住。

<a id="case-pattern-the-content-slog"></a>
## 案例模式：内容苦熬期

一位创始人连续六个月每天在 LinkedIn 发内容，积累800名关注者、约5条线索，成交1单，价值3,000美元。

**表面上：** 失败了。

**实际算账：** 六个月晚间时间换来3,000美元收入，时薪可能相当于25美元。与陌生开发或付费广告相比，投资回报较低。

**但是：** 从长期复利看，800名关注者、内容库和个人品牌可能比这3,000美元更值钱。内容是慢渠道，但会积累。

**调整决策：**

- 急需短期现金：转向陌生开发或付费广告，周期更快。
- 着眼品牌与长期：继续做内容，同时增加陌生开发或付费广告。
- 两边都不起作用：先修正方案或信息表达。

内容价值比陌生开发或付费广告更难衡量，创始人因而容易投入过多——因为做起来感觉不错；或投入过少——因为看不到即时回报。

<a id="case-pattern-speed-to-lead"></a>
## 案例模式：线索响应速度

一位创始人每月获得100条线索，却要24—48小时才跟进，转化率8%。

**修正：** 在5分钟内通过短信和邮件自动跟进。

**研究中观察到的模式：** 响应速度对转化有可测量的影响，通常回应越快，转化越高。具体倍数因来源而异。

通用规则是快速回应。在大多数销售场景中，延迟数天与明显较低的转化率相关。

<a id="case-pattern-the-we-need-a-better-lead-source"></a>
## 案例模式：“我们需要更好的线索来源”

一位创始人认为自己需要更好的线索渠道。可以问：

1. 现有线索的转化率是多少？低于5%，先修正方案。
2. 跟进节奏如何？接触少于5次，先修正跟进。
3. 响应线索要多久？如果按小时算，先提速。
4. 单位经济模型如何？如果终身毛利与获客成本之比（LTGP:CAC）低于3，先修正模型。

很多时候，答案是“先修好转化系统”。漏斗其他环节正常运转，更好的线索才有用。

<a id="anti-pattern-lead-hoarding"></a>
## 反面模式：囤积线索

一位创始人的客户关系管理系统（CRM）里有5,000个名字，却从未联系其中大多数人。

**为什么会发生：** “准备好了再联系。”“他们还不够熟。”“不知道该说什么。”

**现实：** 三个月没跟进的线索，大致已接近陌生线索。名单会快速失效。

**修正：** 要么跟进，要么明确排除。不实际使用的5,000条名单，比不上真正跟进的200条。
